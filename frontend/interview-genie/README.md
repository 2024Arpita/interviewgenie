# InterviewGenie

AI-powered mock interview and interview preparation platform built with the MERN stack.

### Features
- AI-generated interview questions
- Interactive Mock Interview mode
- AI-powered answer evaluation
- Personalized feedback and scoring
- JWT authentication
- MongoDB-based interview persistence

### Tech Stack
**React.js · Node.js · Express.js · MongoDB · JWT · Gemini API**
